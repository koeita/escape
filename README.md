# 密室の謎解き脱出 (Mystery Escape Game)

[![Play Online](https://img.shields.io/badge/Play-Game%20Online-blue?style=for-the-badge&logo=google-chrome)](https://escape.xcangcheng.workers.dev/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/koeita/escape)

さまざまなシチュエーションの密室を舞台にした、本格派のポイント＆クリック型脱出Webゲームです。  
外部ライブラリや重いゲームエンジンを一切使用せず、純粋なWeb標準技術（HTML5 / Vanilla JavaScript / CSS3 / Web Audio API / SVG）のみで制作されています。

## ✨ システムの特徴

- **オールベクターSVGグラフィック**
  - 背景、家具、ギミック、アイテムアイコンに至るまで全てインラインSVGで描画。4KモニターやRetinaディスプレイ、スマートフォンでも一切ぼやけず美しい描画を実現。
- **Web Audio API による自前シンセサウンド**
  - クリック音、解錠音、ドライバー回転音、時計のチクタク音、ファンファーレなどをプログラム上でリアルタイム波形生成。外部音声ファイルのダウンロード待ちなしで即座に再生。
- **オートセーブ ＆ クリアタイム記録**
  - `localStorage` による完全オートセーブ。いつでも途中で中断・再開可能。各ステージクリア時にはクリアタイムが記録されます。
- **スマートフォン最適化 ＆ 日本語タイポグラフィ**
  - スマホでの片手操作に最適化したタッチ操作、レスポンシブ配置、および日本語の文節の途中で文字が不自然に切れない美しい組版を採用。

## 🕹 操作方法

| アクション | 操作（スマホ / PC） |
| :--- | :--- |
| **視点切り替え** | 画面左右の「◀」「▶」ボタンをタップ |
| **調べる / ズーム** | 気になる家具やオブジェクトをタップ |
| **アイテムを選択** | 画面下のアイテムスロットをタップ（金色の枠線が点灯） |
| **アイテムを使う** | アイテム選択状態で、使いたい場所をタップ（またはモーダル内の選択肢から選ぶ） |
| **アイテムを調べる** | 選択中のアイテムスロットを「もう一度タップ」して詳細モーダルを開く（分解・合成が可能） |
| **設定（音量・中断など）** | 画面右上の **歯車（設定）アイコン** をタップ（音量ON/OFF、最初からやり直す、タイトルへ戻る） |

## 💻 ローカルでの開発・実行方法

外部サーバーやビルドツール（Node.js / npm等）は必須ではありません。

1. **リポジトリをクローン:**
   ```bash
   git clone https://github.com/koeita/escape.git
   cd escape
   ```
2. **ブラウザで開く:**
   - `index.html` をお好みのWebブラウザ（Chrome, Edge, Safari, Firefox等）でダブルクリックして開くだけで即座にプレイ・開発可能です。
   - VS Code をお使いの場合は「Live Server」拡張機能での起動も推奨されます。
